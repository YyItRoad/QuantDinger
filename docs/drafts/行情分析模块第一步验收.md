## 边界

这一步只验证页面与接口契约，**没有实现真实分析、周期调度、正式 PostgreSQL 两表迁移、AI 调用、通知或交易**。

演示存储为本模块专用 SQLite 适配器，任务与结果按用户隔离。首次访问生成 24 条示例记录、3 条任务；删除任务保留记录，不重新生成已删除的任务。同品种、交易所、类型和周期禁止重复创建未删除任务。演示状态字段只用于展示，不代表已实现状态判定规则。

正式应用仍复用 login_required，不含测试登录后门。必须显式设置 MARKET_STATE_DEMO_ENABLED=true，以及 MARKET_STATE_DEMO_DB 指向可写的专用演示 SQLite 文件，才能使用演示接口。

默认关闭，接口返回 503；前端展示错误并禁用新增。多个 API 进程必须指向同一个本机文件，不用于跨主机部署。后续正式实现替换适配器，保留接口路径及响应结构。

## 接口

| 方法与路径 | 功能 |
| --- | --- |
| GET /api/market-state/records | 分页、币种及周期筛选，按完成时间倒序 |
| GET /api/market-state/records/:id | 完整结果详情 |
| GET /api/market-state/tasks | 未删除任务列表、筛选与分页 |
| POST /api/market-state/tasks | 新建演示任务 |
| PATCH /api/market-state/tasks/:id | 布尔字段 enabled 控制启停 |
| DELETE /api/market-state/tasks/:id | 软删除，保留历史记录 |

列表参数为 page、page_size（最大 100）、symbol、timeframe。成功响应为 code=1、data、mode=demo；列表 data 包含 items、total、page、page_size、symbols。symbols 来自该页签全部可见数据，不受当前分页或筛选缩减。
