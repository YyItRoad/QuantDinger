# 计划使用说明

更新日期：2026-10-25。适用范围：当前本地验收版本，尚未部署云端。

这块功能用于保存**当时的市场状态、自己的想法，以及后来实际怎么做的**，方便复盘。可以只记录想法；需要时再使用观察、交易关联和复盘。

## 一、日常最常用的两种方式

### 方式 A：开仓时直接记原因

在现有数字货币快捷开仓表单的“开仓原因”中，写清两件事：**现在市场是什么状态，我为什么要开这一笔**。

例如：

> 当前是下跌后的反弹，小时级开始回升。我认为回踩守住后可能继续反弹，所以准备尝试做多；如果关键低点被跌破，说明这个判断不成立。

这是填写示例，不是当前行情判断或交易建议。写自己的真实理由即可，最多 500 字，不要求固定格式。

- 现货买入、合约开仓必须填写。
- 现货卖出、专用平仓、撤单不要求填写。
- 提交仍使用原来的交易流程；原因会随已有快捷交易记录保存。
- 后续打开同一账户、品种的“交易记录”查看原文。

### 方式 B：还没开仓，先记想法

1. 打开“计划”，点击“新建草稿”。
2. 填写一个容易找到的标题，例如“FIL 回踩观察”。
3. 展开决策卡，选择市场、产品类型、交易所和品种，再填写“行情假设”：记录市场状态和自己的想法。
4. 有支持依据或反向证据时一并填写，点击“保存记录”。

**草稿只要求标题，其他内容可以分次补齐。** 暂时只想保留想法，保存为草稿即可，不必进入观察，也不必创建交易记录。

第一次保存具体标的前，请核对市场、交易所、现货/合约和品种。保存后这些身份信息固定，换标的需要新建计划。仅保存标题、尚未选标的的草稿，之后仍能首次补齐。

## 二、怎么使用真实分析记录

“分析”记录保存行情判断及其依据；“计划”保存你准备怎么做。计划可以引用已经保存的分析。

1. 打开“分析”→“分析记录”，点击“查看详情”，核对品种、交易所、现货/合约、周期和数据截止时间。
2. 新建或修订同一标的的交易计划，展开研究来源部分，点击“新增研究来源”。
3. 来源类型选择“分析记录 ID”，再从下拉框选择对应记录，不用手填 ID。
4. 保存后，在计划详情的“研究来源与证据”查看所引用的摘要和截止时间。

引用其他品种或已知市场身份不匹配的分析会被拒绝。分析摘要由系统读取，不能在计划中手工篡改；需要新依据时选择新的分析记录，再保存修订。

**让助手分析行情，不等于已经生成网页记录。** 如果希望分析、计划都能在网页看到，可以明确这样说：

> 在本地，用 FIL/USDT（OKX 现货）的真实已收盘行情生成并保存分析记录，再创建一份引用这些记录的交易计划。记录市场状态、观察想法、触发条件和失效条件；资料不足就注明。保存后回读确认，并告诉我去哪个页面查看。只记录研究，不下单、不启用自动交易。

本地已提供“真实数据验收：FIL 做多观察（10-25）”样本，引用分析 #1（4 小时）和 #2（1 小时）。这些是 2026-10-25 当时保存的行情快照，不会自动变成最新分析。

当前本地样本的结构化判断由本对话生成，通过现有分析服务保存，再通过 MCP 保存引用计划。网站内置模型和后台分析任务尚未在这套新环境联通，网页“立即分析”及周期自动分析尚未完成验证，不能当成已经可用的完整自动流程。

## 三、需要跟踪条件时，再进入观察

打开草稿，点击“修订计划”，补齐页面提示的文字决策卡内容：

| 字段 | 写什么 |
| --- | --- |
| 主策略 | 这次主要准备做什么，例如“突破后的回踩观察” |
| 判断周期、决策周期 | 用哪个周期判断环境，用哪个周期判断是否行动 |
| 行情假设 | 当前市场状态，以及你的判断 |
| 入场触发条件 | 出现什么情况才考虑行动 |
| 失效条件 | 出现什么情况说明原判断不成立 |
| 止盈与其他退出规则 | 后续准备如何退出 |
| 等待或放弃条件 | 什么情况下继续等，什么情况下放弃 |
| 支持依据 | 判断基于什么事实；反向证据有则填写 |

保存后点击“进入观察”。资料未补齐时，页面会指出缺项。

“观察中”表示你在跟踪这份计划，**不会自动监控、提醒或下单**。观察到新情况时，可以点击“记录信号判断”，填写判断、原因和实际观察时间。

“信号已确认”只是一条判断记录，不代表已经成交。AI 建议不能冒充人工确认。修订计划后，新版本信号会重新变为“未评估”。

## 四、想法变了，怎么修改

1. 打开计划，点击“修订计划”。
2. 修改想法、条件、周期、有效期或参考风险参数。
3. 核对页面显示的修改前后差异，填写修订原因，例如“小时结构变化，先继续等待”。
4. 点击“保存记录”。

每次保存追加一个新版本。旧内容在“版本与内容”中查看；状态变化和信号判断在“决策日志”中查看。

| 内容 | 修改规则 |
| --- | --- |
| 标题、想法、条件、方向、周期、有效期、参考风险输入 | 草稿及观察中的计划可以追加修订 |
| 已保存的标的、市场、交易所、产品类型、原生标识及结算币 | 固定，不能改成另一标的或清空 |
| 引用哪条分析 | 可以增减、更换，但必须符合标的身份 |
| 原分析、历史计划版本、旧决策日志 | 不能覆盖改写 |
| 已有交易记录采用的版本、账户、环境和初始风险 | 固定，不随新计划版本变化 |

已取消、已结束或已到期的计划不能直接修订。若要继续研究同一标的，可以“复制为新草稿”；换标的直接新建计划。

## 五、风险输入是选填，什么时候填

想比较参考风险时，展开“风险输入（选填）”，填写参考入场价、初始止损价、风险计价币，并在“基础资产数量”和“风险预算”中选一种。

- 基础资产数量：例如研究多少个 FIL，不是投入多少 USDT。
- 风险预算：例如这次研究按多少 USDT 的价格风险计算，不是账户余额或保证金。
- 目标价选填，用于计算目标盈亏比。
- 计划 1R 表示参考入场与初始止损之间的价格风险，不含手续费、点差和滑点。

数量、预算或其他资料未定时可以不填，系统会显示缺口。不要为了让页面显示完整而编造账户资金或数量。填写参考价不会设置交易所止损、止盈或提交订单。

## 六、需要对照实际交易时，再关联

这部分在计划详情的“交易与复盘”页签中。只记研究想法时可以跳过。

如果希望保留可信的事前依据，尽量在实际入场前完成：

1. 点击“新增一次交易记录”。
2. 选择这次实际采用的计划版本、账户，以及实盘或模拟环境。
3. 保存，固定这次采用的版本和参考风险。**这里的“新增”只是登记，不是开仓。**

发生交易后，再点击“关联已有记录”，选择记录类型和具体记录，核对账户、品种、发生时间、价格、数量和归属后保存。有退出成交时，也要关联相应退出事实。

现有快捷交易记录、持仓管理历史详情中的“查看计划/复盘”也可以作为入口；跳转不会自动完成关联。

关联错了，使用“撤销关联”并说明原因；原记录仍保留。原订单或成交后来有变化，使用“刷新事实 / 确认归属”，保留更新前后的依据。

订单或策略引用不等于已经成交；同一笔真实成交不能重复归属。事后才补建的记录应如实标明历史补录，系统不会把它当成可信的事前依据。

本地验收库目前没有配置交易所密钥，也没有真实成交数据；没有可关联交易时，来源列表为空是正常的。

## 七、交易之后怎么复盘

在对应交易记录中点击“写复盘”，分别回答：

1. **行情判断**：当时对市场的理解是否符合后来事实？
2. **策略规则**：这套触发、失效和退出规则是否适用？
3. **实际执行**：实际操作有没有遵守原计划？
4. **下一次改进**：下次具体改变哪一件事？

每项写依据，再填写“本次复盘说明”并保存。交易未结束时可以保存阶段复盘，之后继续追加，旧复盘不会被覆盖。

净收益、净 R 只在实际成交闭合、归属、费用、币种及事前依据等资料可核验时计算。显示“不可评估”时，先看“证据缺口”；仍可以做文字复盘，不用手工填一个收益数字代替真实记录。

观察结束但没有交易，也可以保留记录并结束研究；放弃假设可以取消计划。取消或结束研究不会平仓。仍有关联的持仓、部分退出或归属不明记录时，系统会阻止结束研究。

本次独立本地地址：[交易计划](http://127.0.0.1:18888/#/trade-plans)、[分析记录](http://127.0.0.1:18888/#/market-state)。本机登录信息见仓库 `.local_tools/trade-plan-local/本地登录信息.md`。

1. 在“分析”中查看两条 FIL 记录及其数据截止时间和依据。
2. 在“计划”中打开“真实数据验收：FIL 做多观察（10-25）”，查看想法、等待条件和两条分析引用。
3. 点击“修订计划”，确认标的固定，尝试修改自己的想法并填写修订原因。
4. 保存后打开“版本与内容”，核对新旧内容均保留，新版信号恢复“未评估”。

目前本地样本没有实际成交，先验收到这里即可；后续有可核验的已有交易时再验证关联和复盘。若你已经编辑过样本，以页面当前版本为准。
