# 计划模块

更新日期：2026-10-25。本文描述已实现的 v1 功能；生产发布与验收以[部署与验收](部署与验收.md)记录的时间和版本为准，不将其视为永久实时状态。

本模块用于记录开仓时的市场状态和想法，并在需要时把研究、实际交易和复盘关联起来。网页名称为“计划”，路由保持 `/trade-plans`。网页与 MCP 共用 PostgreSQL 数据。

## 已实现范围

- 数字货币快捷开仓复用“开仓原因”，记录市场状态和想法，不要求先建立计划。
- 仅标题即可保存草稿；按需补齐文字决策卡、分析引用和参考风险。
- 观察、信号判断、修订、取消、到期、结束及复制；内容版本和决策日志可追溯。
- 登记某次交易采用的版本、账户、环境和参考风险，关联已有交易事实。
- 行情判断、策略规则、实际执行分别复盘；缺少证据时显示不可评估。
- 网页与 18 个计划 MCP 工具使用同一领域服务，保留用户隔离、权限、并发校验和幂等。

## 已确定的产品边界

1. 草稿仅标题必填；进入观察需要文字决策卡完整，风险输入可以缺失但须明确提示。
2. 参考风险支持数字货币现货做多、线性合约多空；其他产品可保存文字研究，不能据此宣称可计算风险。
3. 同一成交只允许一个活动归属，不做比例拆分；归属未知保留待确认。
4. 交易登记冻结采用版本和风险依据；补录不能冒充可信事前依据。
5. 终态计划通过复制新草稿继续研究，原计划不重新启用。
6. 计划的保存、观察、关联和复盘不下单、不启停策略、不接管持仓、不修改止损。现有快捷交易属于独立交易流程，继续执行原授权和保护。

本版不包含条件自动监控、自动入场、提醒、自动生成分析任务、聊天自动采集、批量历史导入、MFE/MAE 或复杂统计。现有其他分析、策略复盘功能的可用性不由本模块的验收证明。
